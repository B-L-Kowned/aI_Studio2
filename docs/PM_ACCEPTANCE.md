# PM acceptance gates

Gate 1 Distribution: one binary/app; three entitlement keys; upgrade path.
Gate 2 Onboarding: storage + included/BYO LLM + optional publishing connections.
Gate 3 Planning: template/freeform/import converge on Brief → Outline → Scenes → People → Sources → Decisions.
Gate 4 Long-form/series: 20-minute episode and 20-production series both use same model; runtime planning before scripting.
Gate 5 Collaboration: invite, consent, avatar/voice, scene assignment, optional publish approval.
Gate 6 Existing video: ingest/analyze/enhance path reaches same editor.
Gate 7 Script/production: approved plan drives script; provider-independent previews; versions/stale state.
Gate 8 Render/edit: final render is not terminal; non-destructive post-render editor; scene-level replacement/regeneration.
Gate 9 Publish: common platforms; Prepare Only always available; automation optional.
Gate 10 Zero-credit QA: complete happy paths and failure paths with deterministic mocks before any paid HeyGen call.
